A newspaper-poster entry that sums up the world news of Wednesday 18 November 2026 in one 1024×1024 image: NVIDIA's $115.8bn quarter, Kuwait intercepting drones over the Gulf, Trump in Manila for Quad talks, the UN's October civilian toll for Ukraine, shrinking food rations in Gaza, and SpaceX catching a falling Starship. The artwork is drawn in poster.html (inline CSS and SVG) and rendered to entry.png; main.ts copies that image to the output directory as entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
